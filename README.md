# React Admin Panel

A responsive admin dashboard built with React and TypeScript, featuring authenticated routes and user management.

## Features

Login/session handling via a custom auth context. Protected dashboard route that redirects unauthenticated users. User management module. Centralized Axios instance for API calls. Client-side routing with React Router.

## Tech Stack

React 19, TypeScript, React Router v7, Axios

## Run Locally

Run `npm install` followed by `npm start`. Open http://localhost:3000 to view it in the browser.
